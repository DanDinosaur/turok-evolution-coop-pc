# Turok: Evolution Co-op for PC v1.0

A native **Windows PC** build of the split-screen co-op mod (EvolutionRecomp-based). You need your own **USA Xbox** copy of the game; see the README for setup.

**Download:** [turok-evolution-coop-pc-v1.0.zip](turok-evolution-coop-pc-v1.0.zip) (program, patcher, README). No game files included.

## PC highlights
- 2-player split-screen campaign co-op at 60 fps; one controller = normal single player.
- Mod menu (D-pad Right + Right Bumper): animal / enemy spawns, pets, god mode, all weapons + ammo, health, bring player 2, invisibility, friendly-fire switch, save / load slots.
- Video options in the game's Options menu (resolution, fullscreen, frame limit, draw distance).

## Known issues
- Mod menu does not open on the flying missions.
- Rare crash / stuck music loop on a checkpoint load (restart fixes it).
- Third-person view and vertical split not in yet.
